If Follow does nothing

  1. On a Mac: Podcasts → File → Follow a Show by URL… (often works when iPhone silently fails).
  2. On iPhone: Library → ⋯ → Follow a Show by URL… → paste the URL → Follow. Wait a few seconds; if nothing appears, force-quit Podcasts and retry.
  3. Or use Overcast / Pocket Casts → Add URL with the same feed (more reliable for private RSS).
